高校生がサイバーセキュリティの面白さや重要性に触れ、将来の情報科学系・工学系大学への進学やセキュリティ専門職を目指すための入門ライトノベルです。
第1部（第1話〜第15話）：橘 葵＆城崎 悠真が、パスワード認証から暗号、クラウド、AI防御までの基礎原理を習得して大学進学へ。
第2部 先端編（第16話〜第20話）：新入生の神崎 蓮＆白石 結衣が、IoT、ゼロトラスト、ハードウェア解析、社会重要インフラ防御に挑む！
第2部 横浜国大SPIRAL探訪編（第21話〜第61話）：暗号数理（四方教授・佐藤准教授）、IoT・マルウェア解析（吉岡教授・イン特任准教授・佐々木准教授）、通信・物理層セキュリティ（落合教授）、人工物メトリクス（松本名誉教授）、認知セキュリティ（NICT連携）、セキュリティUX（NTT連携）など最新研究論文の知見を高校生向けにストーリー化！
