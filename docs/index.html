📖 このライブラリについて

高校生がサイバーセキュリティの面白さや重要性に触れ、将来の情報科学系・工学系大学への進学やセキュリティ専門職を目指すための入門ライトノベルです。
第1部（第1話〜第15話）：橘 葵＆城崎 悠真が、パスワード認証から暗号、クラウド、AI防御までの基礎原理を習得して大学進学へ。
第2部（第16話〜第20話）：新入生の神崎 蓮（ハードウェア・IoT班）＆白石 結衣（暗号数理班）が、大学1年となった悠真TAや芹沢准教授と共に、IoT、ゼロトラスト、ハードウェア解析、プライバシー強化技術、社会重要インフラ（自動車・電力）の先端セキュリティに挑みます！
